Maven Java Project

Project Description

This project demonstrates the basic Apache Maven lifecycle using a simple Java application.

Technologies Used

- Java
- Apache Maven
- JUnit

Project Structure

- "pom.xml" - Maven project configuration
- "src/main/java" - Java application source code
- "src/test/java" - Unit test code

Maven Commands

mvn compile
mvn test
mvn package
mvn clean

How to Run

Build the project:

mvn package

Run the application:

java -cp target/classes com.careertiq.app.App

Output

Hello, Maven!
Java application built with Apache Maven.
